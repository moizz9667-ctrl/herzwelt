# HerzWelt – Deutsche Geschichten

Eine deutschsprachige Story-Magazine-Website mit vollständigen Geschichten.

## Live ansehen
👉 [herzwelt.github.io](https://herzwelt.github.io) *(nach dem Deployment)*

## Features
- Light Blue Theme
- 5 Seiten: Startseite, Geschichten, Story-Detail, Über uns, Kontakt
- Dark / Light Mode
- Vollständig responsiv (Mobile + Desktop)
- AdStera Werbeplätze
- Kein Framework – reines HTML/CSS/JS

## Deployment (GitHub Pages)
1. Dieses Repo auf GitHub pushen
2. Repo → Settings → Pages → Source: `main` Branch → `/root` → Save
3. URL: `https://<dein-username>.github.io/herzwelt/`
